# E-Learning Platform

A modern and responsive e-learning platform built with React.js, designed to provide students with an organized learning experience through courses, weekly content, lectures, sections, and an integrated coding compiler.

The project focuses on practicing modern React development, component-based architecture, routing, and building a structured educational platform.

## 📂 GitHub Repository
